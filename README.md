This is the code for the paper DGRAF: Observation-Quality-Aware Reinforcement Learning for Dynamic Reconfigurable Batteries. The goal is to achieve dynamic reconfiguration of energy storage systems under partial observability. 
The core simulation environment of this work was originally prototyped and validated in Simulink (provided as env_8 in the current directory). To enable reinforcement learning training and circumvent software licensing and version limitations, for the convenience of everyone's use, we provide a fully compatible Python simulation environment based on the Rint battery model as the main codebase of this repository.
